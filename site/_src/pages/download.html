What Windows will ask

Lintel is not code-signed yet. A signing certificate costs money every year, and this is a free project. So Windows does not know the file, and SmartScreen shows a blue warning: "Windows protected your PC".

  1. Open the file you downloaded.Your browser may also warn you. Choose Keep.
  2. Click "More info".It is the small link in the blue window.
  3. Click "Run anyway".The installer starts. It does not ask for an administrator.
  4. Finish the installer.Lintel starts, and the island greets you at the top of the screen.

If you would rather not run an unsigned file, that is a fair choice. The whole source is public, and you can build it yourself with the commands below.

What you need

  • Windows 10 or Windows 11, 64-bit. Lintel does not run on macOS or Linux.
  • The WebView2 runtime. Windows 11 has it. On Windows 10 the installer fetches it if it is missing.
  • No account. Lintel has no sign-up and no server of its own.
  • Nothing else to start. A few features need something extra, and each one says so: a key of your own for chat, a download for the voice assistant and dictation, one administrator prompt for hardware sensors.

Updates

Lintel never checks for updates by itself. In Settings, open Apps and click "Check for updates" when you want to look.

Code signing policy

The installer is not code-signed yet, which is why Windows warns. Lintel is applying to the SignPath Foundation's free code signing for open-source projects. Once it is granted, release installers will be signed on these terms:

  • Free code signing provided by SignPath.io, certificate by SignPath Foundation.
  • Built in the open. Every signed installer is built from the public repository by its build workflow on GitHub's own runners, never on a private machine.
  • Committers and reviewers: the repository's contributors. Approvers: the repository's owner.
  • Privacy policy. This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it. The documentation lists what can leave your computer and what turns each thing on.

Until then, each release gives the SHA-256 of its installer, so you can check your download.

How to remove it

  1. Open Windows Settings.Go to Apps, then Installed apps.
  2. Find Lintel and choose Uninstall.The uninstaller takes Lintel's entries out of your agents' settings. It leaves your own data unless you tick the box to delete it.

Build it from source

You need Node.js, the Rust toolchain and the WebView2 runtime on Windows. Then:

git clone {REPO}
cd lintel
npm install
npm run build
npm run tauri dev

npm run pack makes the installer into the release folder. It also builds the hardware helper, which needs the .NET 8 SDK. More detail is in the documentation and on the Contribute page.
